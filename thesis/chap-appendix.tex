\chapter{Appendix}
\label{chap:appendix}

This appendix collects the reproduction commands and the run-level data
for the four pilot runs analysed in Chapter~\ref{chap:results}. The aim
is to make the experiments reproducible end-to-end on a single
workstation, and to surface the per-generation numbers that did not fit
the main body.

\section{Reproduction}
\label{app:reproduction}

The commands below reproduce the four runs from a clean checkout of
the fork. The environment, the bootstrap, and the four scheduler
invocations are listed in order; all four runs were executed with
\texttt{seed=0} and \texttt{generation\_task\_budget\_total=100}, and
they share the same model and benchmark.

\subsection{Environment Setup}

\begin{lstlisting}[language=bash,caption={Environment setup.}]
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
export OPENAI_API_KEY='...'
export ANTHROPIC_API_KEY='...'
docker run hello-world
\end{lstlisting}

\subsection{Initial Archive Bootstrap}

\begin{lstlisting}[language=bash,caption={Bootstrap the initial archive used by every pilot run.}]
python test_swebench.py --benchmark swe_verified_mini --full_mini \
  --agent_dir initial_swe_verified_mini --write_agent_metadata
\end{lstlisting}

\subsection{Scheduler Run Commands}

\begin{lstlisting}[language=bash,caption={Baseline scheduler.}]
python DGM_outer.py --scheduler baseline \
  --max_generation 4 --selfimprove_size 2 --selfimprove_workers 2 \
  --benchmark swe_verified_mini --generation_task_budget_total 100 \
  --seed 0
\end{lstlisting}

\begin{lstlisting}[language=bash,caption={Genetic Algorithm scheduler.}]
python DGM_outer.py --scheduler ga \
  --max_generation 4 --selfimprove_size 2 --selfimprove_workers 2 \
  --benchmark swe_verified_mini --generation_task_budget_total 100 \
  --ga_tournament_k 3 --ga_mutation_temperature 1.0 \
  --seed 0
\end{lstlisting}

\begin{lstlisting}[language=bash,caption={Hyperband scheduler.}]
python DGM_outer.py --scheduler hyperband \
  --max_generation 4 --selfimprove_size 2 --selfimprove_workers 2 \
  --benchmark swe_verified_mini --generation_task_budget_total 100 \
  --hyperband_eta 5 --hyperband_budgets 2,10,50 \
  --hyperband_initial_children 15 \
  --seed 0
\end{lstlisting}

\begin{lstlisting}[language=bash,caption={ASHA scheduler.}]
python DGM_outer.py --scheduler asha \
  --max_generation 4 --selfimprove_size 2 --selfimprove_workers 2 \
  --benchmark swe_verified_mini --generation_task_budget_total 100 \
  --hyperband_eta 5 --hyperband_budgets 2,10,50 \
  --hyperband_initial_children 15 \
  --seed 0
\end{lstlisting}
