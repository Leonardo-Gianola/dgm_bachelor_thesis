\begin{abstract}
  The Darwin G{\"o}del Machine (DGM) is an evolutionary framework in
  which a population of coding agents rewrites its own source code,
  evaluates the resulting children on SWE-bench, and keeps the most
  promising offspring in an archive that seeds the next generation.
  Language models have become capable enough at programming to act as
  such autonomous agents: programs that pursue a goal, search and edit
  files, run tests, and iterate in a reason-act loop. One bottleneck
  of this loop is that most of the compute invested per generation
  goes into evaluating children that ultimately fail to improve the
  parent. This thesis investigates whether \emph{multi-fidelity
  evaluation schedulers} can reduce wasted compute without sacrificing
  the final accuracy of the evolved agents. We extend the DGM with
  several schedulers (a sequential \texttt{baseline}, synchronous
  \texttt{hyperband}, asynchronous \texttt{asha}, and a blind
  high-temperature genetic algorithm \texttt{ga}) and compare them on
  a fixed subset of SWE-bench Verified using the same self-improvement
  budget, model, and initial archive. Across single-seed pilot runs,
  the genetic algorithm reaches a competitive peak accuracy at the
  lowest cost, while Hyperband attains the highest peak but spends
  considerably more. Overall, this work shows that the choice of
  evaluation scheduler is a non-trivial knob in self-improving systems
  like the DGM, and gives a first cost-versus-accuracy reading of four
  candidates on SWE-bench Verified.
\end{abstract}
