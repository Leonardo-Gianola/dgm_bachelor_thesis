\section{Operational Guards}
\label{sec:guards}

Long DGM runs are sensitive to a class of silent failures in which a child
agent fails to evaluate but still consumes its full budget.  We add three
guards to keep these from polluting the comparison.

\paragraph{Argparse guard.}
The eval harness invokes the modified \texttt{coding\_agent.py} with a fixed
set of command-line flags
(\texttt{--problem\_statement}, \texttt{--git\_dir}, \texttt{--chat\_history\_file},
\texttt{--base\_commit}, \texttt{--outdir}, \texttt{--test\_description},
\texttt{--self\_improve}, and either \texttt{--instance\_id} for SWE or
\texttt{--language} for polyglot).  If the LLM-proposed patch removes or
renames any of these flags, every per-task invocation exits with code 2 and
the child silently burns its budget.  After applying the patch we run
\texttt{python /dgm/coding\_agent.py --help} inside the container and verify
that the expected flag names appear in the help text; otherwise the child
is marked \texttt{model\_patch\_notempty=False} with an explicit
\texttt{compile\_failure\_reason} and skipped.

\paragraph{Empty-patch retry.}
Children that produce an empty patch on the first attempt are retried once
at a higher LLM temperature before being discarded.
